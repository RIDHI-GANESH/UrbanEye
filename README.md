# UrbanEye

## AI-Powered Urban Infrastructure Intelligence, Prediction and Response Management System

### Problem Statement
Urban areas face infrastructure problems such as potholes, garbage accumulation, waterlogging and delayed maintenance. Traditional complaint systems often lack intelligent prioritisation, predictive analysis and coordinated response management.

### Proposed Solution
UrbanEye is an AI-powered web application that helps citizens report infrastructure problems and enables municipal administrators to detect, prioritise, monitor and manage these issues using artificial intelligence, geospatial intelligence and predictive analytics.

### User Roles
- Citizen
- Municipal Administrator
- Field Worker
- Contractor

### Technology Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS, Leaflet

**Backend:** Python, FastAPI, REST APIs, SQLAlchemy, JWT

**Database:** PostgreSQL, PostGIS

**AI/ML:** Python, Pandas, NumPy, Scikit-learn, OpenCV, YOLO, PyTorch

**Tools:** VS Code, Git, GitHub, Postman, Jupyter Notebook, Docker

### Main Modules
1. Citizen Complaint Management
2. Passive Vehicle-Based Infrastructure Monitoring
3. AI-Based Image Detection
4. Intelligent Complaint Prioritisation
5. Flood and Drain Risk Assessment
6. Contractor and Warranty Management
7. Proof-of-Fix Verification
8. Emergency Navigation Simulation
9. Geospatial Intelligence
10. Predictive Analytics
11. AI Municipal Assistant
12. Analytics and Reporting

### Project Structure

- `frontend/` - User interface
- `backend/` - Backend APIs and business logic
- `ai/` - Machine learning and computer vision
